Earlier v1 files are retained for comparison. No direction is approved yet.

- A, Connected N: strongest legibility at small sizes, direct name recognition;
  recommended. Risk: an initial-based mark needs distinctive colour and consistent
  usage to build recognition in a crowded category.
- B, Welcome Home: warmer doorway/arrival association. Risk: can suggest property
  or hospitality; its internal path is less clear at the smallest sizes.
- C, Meeting Shores: abstract connection between two sides. Risk: less immediate
  meaning and more fragmented at favicon sizes.

Two build/audit passes were run. V2 snaps A's diagonal edges to 45 degrees, opens
B's inner gap and increases clearances around C's diagonal. All three V2 symbols
pass the bundled structural SVG audit with no reported issues. That is a heuristic
geometry check, not proof of originality, legal clearance or finished production.

V3 retains the V2 symbols, corrects the custom wordmark N diagonals to 60 degrees
and removes excess right padding from the lockup canvas. All three V3 lockups
also pass the structural audit without reported issues. V3 overview was rendered
and visually reviewed after these changes.

Rendered and visually reviewed both concept-sheet passes and V2's test sheet
(the screenshot covers its overview and the first symbol's detailed tests).
The concept sheet includes all symbols at 64/32/16 pixels and all name lockups.
The test HTML includes further backgrounds, reverse, mirror, rotation, context
and reference comparisons for all three; not every section was visually inspected.

Wordmark: custom constructed filled paths for Nadorly; no external font files,
embedded raster images or live text in the individual logo SVG files. Presentation
labels use system fonts. Geometry can be regenerated with build_concepts.py.

Reference library: travel-transport summary and exemplary letterform constructions
were consulted. No reference mark was traced. This is not a comprehensive competitor
or trademark search. Brand/name clearance remains open before public launch.
