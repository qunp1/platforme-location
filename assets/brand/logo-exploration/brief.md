# Nadorly logo exploration

Working brief: a car-rental intermediary connecting local agencies in Nador with
travelers, especially Moroccans/Rifians returning from abroad. Build trust with
both travelers and agency partners. Brand name exactly: Nadorly.

Assumed character: welcoming, dependable, local, clear, quietly energetic.
Uses: responsive website header, agency dashboard, future app icon, partner pitch.
French/Arabic/English interface; the primary Latin wordmark remains Nadorly.
No invented Arabic brand spelling in this exploration.

Avoid car silhouettes, steering wheels, keys, map-pin clip art, flags, airline
marks and generic speed swooshes. No claim of affiliation with a local landmark
or agency. Work in monochrome first. Colour/complete kit follows a chosen concept.

Word map: Nador / return / welcome / connection / agency / traveler / coast /
threshold / route / belonging. Strong intersections: N + route, return + doorway,
coast + connection. The mark must identify rather than illustrate all services.

## Concept longlist

Scores are design judgments, each out of 5: clarity / distinction / simplicity /
relevance / small-size strength.

| Idea | Type | Scores | Decision |
| --- | --- | --- | --- |
| Two rounded uprights and a diagonal crossing form an N as a connected route | Letterform | 5/4/5/5/5 | Build A |
| An open doorway carries a short incoming path, evoking a welcome home | Abstract/pictorial | 4/4/5/5/4 | Build B |
| Two offset bays interlock across a diagonal channel, evoking meeting shores | Abstract | 3/4/4/4/4 | Build C |
| The word's y returns underneath the name | Wordmark | 3/3/4/4/2 | Too dependent on full word |
| A circular arrow returns to Nador | Abstract | 4/1/5/5/5 | Familiar navigation convention |
| A road loops into a key | Pictorial | 4/2/3/3/2 | Literal rental cliché |
| Two small arches join as a gateway | Abstract | 3/3/4/4/3 | Too close to generic architecture |
| A horizon notch cuts a bold N | Letterform | 3/3/4/4/3 | Less clear initial |
| A folded ticket forms an N | Letterform | 3/3/3/3/3 | Suggests ticketing rather than rental |
| A single wave becomes a lower-case n | Letterform | 3/2/4/4/4 | Coast cliché, weak distinction |

Construction intentions: generous shapes and counters, black on white, 256-unit
symbol viewBox. A uses consistent rounded ribbon widths; B uses an open portal
with a thick inward path; C uses paired rounded elbows. Wordmarks are outlined
from a locally available font if permitted; exact font recorded with delivery.

All are original explorations. No trademark clearance or exclusivity asserted.
