# Round two review

Latest comparison: nadorly-round2-v2.png (editable board SVG alongside it).

A: a-v2-symbol.svg and a-v2-lockup.svg. Completely empty pointed gateway;
no interior path, key or other object. Original vector geometry and constructed
wordmark. Recommended for continuity with the user's doorway preference.
Risk: architecture/hospitality associations, so context and name remain important.

B: b-v2-wordmark.svg. Custom lowercase lettering, an open n and extended return
on the y. V1's tall first glyph read too much like an inverted U; V2 restores a
recognisable lowercase n, increases l/y spacing and balances the canvas margins.
Risk: the doorway connection is subtler; use the name at readable sizes.

C: c-v1-wordmark.svg. Georgia Bold, individually outlined using the installed
Windows typeface with adjusted glyph spacing. No font file is distributed, and
no font needs to be installed to render the SVG. This is a typography direction,
not a claim of entirely custom letter construction. Risk: less distinctive and
less obviously related to mobility than the other two directions.

Checks: two rendered comparison passes visually reviewed; A's 16/32/48-pixel
scale tests and the three-way one-colour/reversed overview reviewed from tests.png.
The complete generated tests.html contains further sections that were not all
visually inspected. A symbol/lockup and B wordmark have no structural audit
warnings. C retains font-derived near-horizontal serif edges and higher path
complexity; its audit warnings are documented rather than presenting a clean bill.
These are concept checks, not final production approval or trademark clearance.

The first round remains rejected. No new direction is approved. Per the skill's
checkpoint, colour variants, final icon design and full kit follow user selection.
