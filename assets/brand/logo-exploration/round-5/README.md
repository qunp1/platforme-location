# Further logo exploration

User requested new variants after the B2 working kit. The kit is preserved; no replacement is approved. Three variations keep the entrance-and-car idea while changing its character.

01: lower, wider body; broad upper counter; pill headlights. Recommended to reduce the bus-like height.
02: horseshoe entrance and separated compact vehicle; more regional architectural character, but greater detail and weaker tiny-size separation.
03: protruding bumper and distinct wheels; more explicitly automotive, but potentially more badge-like.

All custom filled SVG paths. Existing outlined wordmark is held constant. No new trademark search; no clearance claim.
