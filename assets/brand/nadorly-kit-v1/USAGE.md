# Nadorly — working logo kit v1
2026-10-19 · Selected direction: B2, Softer arrival. This is a working identity, open to refinement.

## Idea
A front-facing car and a pointed welcoming entrance share one silhouette: mobility for people returning to Nador, through local rental agencies. The entrance is an architectural suggestion, not a traced local monument.

## Files and use
- `svg/nadorly-horizontal-green.svg`: website header and partner materials.
- `svg/nadorly-stacked-green.svg`: portrait compositions.
- `svg/nadorly-symbol-green.svg`: standalone mark, at least 32px square.
- `svg/nadorly-symbol-small.svg`: optical cut for 16–24px; headlights are opened up.
- `svg/nadorly-wordmark-green.svg`: name only where the symbol already appears nearby.
- `svg/*-white.svg` and `*-cream.svg`: optically adjusted reversed symbols on dark backgrounds.
- `png/`: transparent raster exports. Keep SVG as the source of truth.
- `web/`: favicon, Apple touch icon, PWA icons, manifest and HTML integration snippet. Paths assume these files are served at the website root; adjust if hosted elsewhere. Maskable icon uses a conservative safe zone.
- `presentation/`: illustrative applications, not evidence of real agency partnerships.

## Clear space and sizes
Keep clear space equal to one arch leg width (28 units on the 256-unit symbol canvas) outside the visible artwork. Existing canvas padding is not a substitute for that external clearance.
Horizontal: recommended minimum 150px wide. Stacked: 140px wide. Name only: 100px wide. Symbol: 32px; use the small optical cut at 16–24px. Preliminary print minimums: horizontal 35mm, symbol 8mm; proof on the actual substrate before manufacturing. At 16px the silhouette leads; do not expect every car detail to read independently.

Cream/green contrast: 6.61:1 (computed sRGB relative luminance). This describes the colour pair, not an accessibility audit of a website. CMYK/spot conversions are intentionally not specified without a printer profile; these are RGB digital masters.

## Lettering
The logo uses the existing custom path-built Nadorly lettering from the concept exploration, with fixed spacing. Logo SVGs have no live font dependency. Do not type the name in another font to recreate the logo. A complete interface type system, especially Arabic typography, remains to be designed separately.

## Placement
Use green or ink on cream/white. Use the supplied white/cream versions on green/ink. On photography, use a quiet area or solid field. Keep proportions and the fixed layouts; avoid rotation, shadows, outlines and replacing negative counters with white shapes. The counters are transparent geometry.

## Status and limits
The user selected B2 as the direction. Colour is a proposal in this version, not an independently approved final palette. All prior concepts are preserved. Category research found many car/pin marks; no professional trademark clearance or name availability search has been performed. No exclusivity is claimed. No Arabic brand spelling has been invented. This folder contains digital SVG/PNG/ICO assets, not certified CMYK print artwork or an AI/EPS source.
